# 审核后台 (Review Admin)

独立的视频审核和用户管理后台系统。

## 功能模块

### 1. 视频审核
- 查看所有视频列表（表格式）
- 视频详情预览（播放、封面、标题、描述）
- 审核操作：
  - ✅ 通过审核
  - ❌ 拒绝（需填写原因）
  - 🚩 标记问题
- 内容分类：正常/成人内容
- 筛选条件：审核状态、内容类型、标题搜索

### 2. 用户管理
- 查看所有用户列表
- 用户详情（基本信息、账户信息、账号状态）
- 用户操作：
  - 🚫 封禁用户（需填写原因）
  - ✅ 解除封禁
- 筛选条件：封禁状态、用户名/昵称搜索
- **权限限制**：不能调整用户余额

### 3. 资金流水查看
- 查看所有用户的资金交易记录
- 实时统计：收入、支出、净额
- 筛选条件：交易类型、时间范围
- 交易类型包括：充值、奖励、送礼、收礼、游戏、红包等
- **权限限制**：只读，不能修改或删除记录

## 技术栈

- **前端框架**: React 19 + TypeScript
- **UI 框架**: Ant Design 6
- **后台框架**: Refine.js 5
- **路由**: React Router v7
- **数据库**: Supabase (PostgreSQL)
- **构建工具**: Vite 7

## 部署

- 生产环境: 可配置

### 环境变量
在 `.env` 文件中配置：
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 安全说明

1. **认证**: 使用 Supabase Auth，仅支持用户名密码登录
2. **权限验证**: 每次请求都会验证用户是否为审核员
3. **RLS 策略**: 数据库层面限制审核员只能访问允许的资源
4. **操作限制**: 审核员无法修改敏感数据（余额、权限等）

## 注意事项

- 审核员账号密码与用户名相同，生产环境请修改
- 封禁用户后，用户将无法登录和使用平台功能
- 所有审核操作都会记录在数据库中
- 资金流水仅供查看，不可修改
